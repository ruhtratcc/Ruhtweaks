# Fontes oficiais consultadas

Consulta em 01/11/2026. Os links não são endpoints de download improvisados. Artefatos GitHub são resolvidos pela API pública de releases, nunca por uma URL formada a partir de versão presumida.

- [WinGet install](https://learn.microsoft.com/en-us/windows/package-manager/winget/install), [list](https://learn.microsoft.com/en-us/windows/package-manager/winget/list), [upgrade](https://learn.microsoft.com/en-us/windows/package-manager/winget/upgrade), [repair](https://learn.microsoft.com/en-us/windows/package-manager/winget/repair).
- [Manifestos oficiais WinGet](https://github.com/microsoft/winget-pkgs/tree/master/manifests). Os diretórios dos IDs do catálogo foram consultados na API do repositório. `RiotGames.RiotClient` retornou 404.
- [Atlas instalação](https://docs.atlasos.net/getting-started/install/install-playbook/), [releases](https://github.com/Atlas-OS/Atlas/releases), [playbook revisado](https://github.com/Atlas-OS/Atlas/blob/0.5.0-hotfix/src/playbook/playbook.conf).
- [AME aplicação de playbook](https://docs.amelabs.net/installing_playbooks/playbook_apply.html), [verificação](https://docs.amelabs.net/developers/verification.html).
- [Litecord confirmado](https://github.com/Ak4ai/Litecord), [releases](https://github.com/Ak4ai/Litecord/releases). Não confundir com ByicTeam/LiteCord, Lightcord ou projetos de servidor Discord.
- [AMD Auto-Detect](https://www.amd.com/en/resources/support-articles/faqs/GPU-131.html), [NVIDIA drivers](https://www.nvidia.com/en-us/drivers/), [Intel DSA](https://www.intel.com/content/www/us/en/support/detect.htm).
- [Brave políticas](https://support.brave.app/hc/en-us/articles/360039248271-Group-Policy), [Mozilla políticas](https://mozilla.github.io/policy-templates/). A pesquisa do Brave usa políticas com backup e reversão; outros navegadores permanecem assistidos. Extensões não são gerenciadas.
- [WMI](https://learn.microsoft.com/en-us/windows/win32/wmisdk/wmi-start-page), [PackageManager por usuário](https://learn.microsoft.com/en-us/uwp/api/windows.management.deployment.packagemanager.findpackagesforuser), [URIs oficiais das Configurações](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings).
- [Slint Rust](https://docs.slint.dev/latest/docs/rust/slint/), [fonte do Slint 1.13.1](https://github.com/slint-ui/slint/tree/v1.13.1), [rustup](https://rust-lang.github.io/rustup/installation/other.html), [LLVM-MinGW](https://github.com/mstorsjo/llvm-mingw/releases).

A revisão de automação, manifestos Riot regionais, políticas Brave, APIs de energia e proteção de anexos estão documentados em [AUTOMACAO](AUTOMACAO.md).
